ABOUT THE PROJECT

Product Price Analysis System

A Python project for collecting, cleaning and exploring product listing data.

OVERVIEW

From listings to insights

This project gathers product information from several websites into a shared dataset, applies cleaning and analysis steps, then presents the resulting catalog through a Flask web application.

PROBLEM

Scattered product information

Product names, recorded prices, ratings and availability are distributed across separate source websites, making a consolidated view harder to explore.

OBJECTIVES

One inspectable workflow

  • Collect source listings through project scrapers.
  • Combine and clean records for analysis.
  • Summarize products and provide searchable views.
  • Keep source links available for verification.

TECHNOLOGIES

Project stack

PythonFlaskPandasPlaywrightMatplotlibBootstrapChart.js

The web interface uses Bootstrap and Chart.js in the browser; existing static charts are generated with Matplotlib.

WORKFLOW

Collection to dashboard

  1. Scraping: source-specific scripts in scraping/ use Playwright to collect listings.
  2. Combining: analysis/combine_datasets.py brings source CSVs together and labels websites.
  3. Cleaning: cleaning/data_cleaning.py normalizes fields and numeric values into the canonical cleaned CSV.
  4. Analysis: analysis/analyze_products.py calculates summary tables; comparison/compare_products.py identifies same-name listings for review.
  5. Visualization: visualizations/visualize_products.py exports static PNG charts; this website adds a dataset-driven interactive overview chart.

LIMITATIONS

Interpret with care

  • Currency metadata is absent, so recorded amounts are not normalized or reliably comparable across sites.
  • Identical product names do not establish matching variants or specifications.
  • Ratings and availability are incomplete for some listings.
  • Data is a CSV snapshot and may not reflect current website listings.

FUTURE ENHANCEMENTS

Possible next steps

  • Capture and validate currency, product variants and scrape timestamps.
  • Add automated data-quality checks and repeatable tests.
  • Track changes across scrape snapshots.
  • Expand accessible interactive analysis with verified fields.
